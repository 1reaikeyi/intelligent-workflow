## 数据库设计文档

| 序号 | 数据表名      | 中文名称     |
| ---- | ------------- | ------------ |
| 1    | chat_session  | 会话信息     |
| 2    | chat_record   | 对话记录     |

### 1. chat_session

chat_session 表为会话信息表，用于存储用户的 AI 对话会话数据。每个会话包含独立的上下文，用户可通过多个会话进行多轮对话。具体表结构如下：

| 字段名      | 数据类型    | 说明         | 备注                          |
| ----------- | ----------- | ------------ | ----------------------------- |
| id          | bigint      | 主键         | 数据id                        |
| session_id  | varchar(32) | 会话id       | 全局唯一标识，业务查询使用    |
| user_id     | bigint      | 用户id       | 关联用户表，默认0表示未登录   |
| title       | varchar(100)| 会话标题     | 可为空，用于会话列表展示      |
| create_time | datetime    | 创建时间     | 默认当前时间                  |
| update_time | datetime    | 更新时间     | 更新时自动刷新                |

**索引说明：**

| 索引名              | 字段         | 说明           |
| ------------------- | ------------ | -------------- |
| session_id_index    | session_id   | 唯一索引，快速查询会话 |
| user_id_index       | user_id      | 普通索引，按用户查询会话 |
| update_time_index   | update_time  | 普通索引，按更新时间排序 |

### 2. chat_record

chat_record 表为对话记录表，用于存储用户与 AI 之间的完整对话内容。每个记录对应一个会话中的一次问答交互，支持多轮对话的上下文追溯。具体表结构如下：

| 字段名          | 数据类型      | 说明         | 备注                          |
| --------------- | ------------- | ------------ | ----------------------------- |
| id              | bigint        | 主键         | 数据id                        |
| conversation_id | varchar(100)  | 对话id       | 关联 chat_session 的会话id    |
| data            | text          | 对话数据     | 存储对话的完整JSON数据        |
| create_time     | datetime      | 创建时间     | 默认当前时间                  |
| update_time     | datetime      | 更新时间     | 更新时自动刷新                |

**索引说明：**

| 索引名                   | 字段            | 说明               |
| ------------------------ | --------------- | ------------------ |
| conversation_id_index    | conversation_id | 按会话查询所有对话记录 |
| create_time_index        | create_time     | 按时间排序对话记录     |
